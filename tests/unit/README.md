# Unit Tests

Contains zero-dependency unit tests runnable with Node.js built-in test runner (`node --test`).

## Core Test Targets
- `normalize.test.js`: Devanagari numerals to ASCII, date format conversions.
- `intents.test.js`: Spoken intent classifications, zero-hallucination property tests.
- `compare.test.js`: Equality vs swapped day/month, name normalization.
