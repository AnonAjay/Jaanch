# Project memory

Antigravity-style persistent context is just files in this repo that every agent reads.
- `AGENTS.md` (root): rules and roles.
- `docs/PROJECT_BRIEF.md`: the why and the scope.
- `docs/ARCHITECTURE.md`: contracts and build plan.
- `.agents/memory/STATE.md`: live progress log. Agents append to it after each task.
- `docs/DECISIONS.md`: one line per decision, with the date.

Rule: if a decision or fact is only in chat, it does not exist. Write it down here.
