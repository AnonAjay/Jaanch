# Demo and submission skill

Rules come from gnani.ai/internship (read 9 Nov 2026). Re-read the page and the full terms before submitting.

## README sections
What it does; how it works (data flow, which arrows carry personal data); measured results (copy the eval table only); limits (prototype, synthetic data, no cafe has used it); models used (Prisma, Timbre, versions exactly as called); each member's contribution; how to run; fallback status if the extension fell back to the in-page overlay.

## 60-second video shot list (mark each shot REAL or STAGED)
- 0 to 10 s: staged scene at a counter, labelled as a dramatization.
- 10 to 45 s: REAL screen recording on the mock portal: Recheck, large text, spelled letters, customer reply, a seeded mismatch flagged, operator decision.
- 45 to 55 s: text card: "Prototype. Tested on synthetic data. The operator decides."
- 55 to 60 s: name and hashtags.
No AI-generated footage of the product. No real brand logos.

## Post
Early in the day, on LinkedIn and X, both hashtags (#GreatIndianAIInternshipChallenge #GnaniAI), tag Gnani. No paid promotion, no engagement swaps. Link the repo and the video.

## Submission
Working demo or video, written explanation, models named, contributions, post links. Submit by the afternoon, not 11:59 PM.

## Never claim
"Solves", "prevents errors", "legal", "accurate" without a number from the eval table.
